# שכפול כרטיס כניסה MIFARE Classic 1K למדבקת RFID — מדריך מלא

> ⚠️ **שימוש מורשה בלבד.** המדריך נכתב לשכפול **כרטיס פרטי שלך** לצורך נוחות
> (להחליף כרטיס פיזי במדבקה שנוסעת עם הטלפון). שכפול כרטיס של אדם אחר או גישה
> למקום ללא הרשאה היא עבירה. השתמש בזה רק על אישור הגישה שלך עצמך.

---

## תקציר (TL;DR)

הכרטיס שלנו הוא **MIFARE Classic 1K**, ריק מנתונים, עם **מפתחות ברירת מחדל**,
והמערכת מזהה **לפי ה-UID בלבד**. לכן השכפול פשוט:

1. קורא את הכרטיס באפליקציית **MIFARE Classic Tool (MCT)** מהטלפון (אנדרואיד).
2. מזמין **מדבקת RFID מסוג "Magic" עם UID ניתן לשינוי** (Gen2 CUID, ‏13.56MHz).
3. כותב את ה-Dump (כולל בלוק 0 / ה-UID) למדבקה מ-MCT.
4. מדביק את המדבקה מאחורי הטלפון / בכיסוי — ומצמיד לקורא.

**עלות:** כמה שקלים למדבקה. **זמן:** דקות. **חומרה מיוחדת:** לא נדרשת.

## מה חשוב להבין קודם

### למה אי אפשר "לשים את הכרטיס בטלפון" (אמולציה)

טלפון אנדרואיד **לא יכול לחקות** MIFARE Classic:

- מנגנון ה-HCE של אנדרואיד תומך רק ב-**ISO 14443-4 (IsoDep)** עם AID.
- MIFARE Classic הוא **ISO 14443-3A** עם הצפנת **Crypto1** — שכבה שה-HCE לא חושף.
- אין אפליקציה, root או טריק שמשנה את זה.

לכן הפתרון הוא **שכפול לפורמט פיזי דק** (מדבקה) שנוסע עם הטלפון — לא אמולציה.

### למה Proxmark3 לא נחוץ כאן

Proxmark3 נחוץ רק כאשר הכרטיס משתמש ב**מפתחות לא-סטנדרטיים** וצריך לשחזר אותם
(mfoc / hardnested). הכרטיס שלנו משתמש במפתחות ברירת מחדל (`FFFFFFFFFFFF`), ולכן
אפליקציית MCT מהטלפון מספיקה לגמרי. Proxmark גם לא "שם את הכרטיס בטלפון" — הוא
מכשיר נפרד.

## אבחון הכרטיס — איך יודעים שזה המצב

סרוק את הכרטיס עם **NFC Tools** או **MCT** וודא:

| שדה | ערך צפוי | משמעות |
|---|---|---|
| Tag type | `ISO 14443-3A` | קרבה 13.56MHz |
| Chip | `NXP MIFARE Classic 1K` | הצ'יפ הנפוץ בבקרת כניסה |
| SAK / ATQA | `0x08` / `0x0004` | מאשר Classic 1K |
| Memory | `1KB, 16 sectors x 4 blocks` | מבנה סטנדרטי |

בקריאת MCT, בדוק:

- **כל הסקטורים נקראים (ירוק)** → מפתחות ברירת מחדל, אין הצפנה מיוחדת.
- **בלוקי הנתונים ‎`00...00`‎** → הכרטיס ריק, אין מידע ייחודי מלבד ה-UID.
- **Sector trailer** ‎`FFFFFFFFFFFF | FF078069 | FFFFFFFFFFFF`‎ → Key A / Access bits / Key B ברירת מחדל.

אם זה מה שאתה רואה → **המערכת מזהה לפי UID בלבד**, וזה התרחיש הקל ביותר.

> אם יש סקטורים **אדומים** (לא נקראו) — המערכת כנראה משתמשת בנתונים מוצפנים עם
> מפתחות לא-סטנדרטיים, ואז MCT לא יספיק. במקרה כזה צריך **Proxmark3** לשחזור
> מפתחות. ראה סעיף "פתרון תקלות".

## פירוק בלוק 0 (בלוק היצרן)

בלוק 0 מכיל את ה-UID ואת נתוני היצרן. לדוגמה (החלף בערכים שלך):

```
XXXXXXXX  BB  SS  AAAA  MMMMMMMMMMMMMMMM
   │       │   │    │          │
   │       │   │    │          └── נתוני יצרן (Manufacturer data)
   │       │   │    └───────────── ATQA (למשל 0004)
   │       │   └────────────────── SAK  (למשל 08)
   │       └────────────────────── BCC  (Block Check Char = XOR של 4 בייטי ה-UID)
   └────────────────────────────── UID  (4 בייט — זה ה"סוד" שלך)
```

- **UID** = ארבעת הבייטים הראשונים. זה מה שהמערכת בודקת.
- **BCC** = XOR של ארבעת בייטי ה-UID. חייב להיות תקין אחרת הקורא לא יזהה.
  כרטיסי Gen2 טובים מחשבים אותו אוטומטית; ודא ב-MCT שהבלוק תקין לפני כתיבה.

## מה להזמין — מדבקת RFID נכונה

חייבים **שלושה** תנאים, אחרת לא יעבוד:

| תנאי | לחפש | למה |
|---|---|---|
| תדר | `13.56MHz` | להתאים לכרטיס |
| צ'יפ | `MIFARE Classic 1K` / `S50` תואם | להתאים לפורמט |
| UID ניתן לשינוי | `Magic` / `UID changeable` / `CUID` / `Gen2` | לכתוב את ה-UID שלך |

### מונחי חיפוש (AliExpress / eBay)

- `UID changeable 13.56MHz MIFARE 1K sticker`
- `Magic MIFARE Classic 1K CUID sticker`
- `Gen2 CUID rewritable NFC label 13.56MHz`

### Gen2 מול Gen1a

- ✅ **Gen2 (CUID) — מומלץ.** כותבים בלוק 0 בפקודה רגילה, MCT עושה זאת ב-`WRITE DUMP`
  בלי טריקים. יותר "שקט" מול קוראים.
- ⚠️ **Gen1a (UID)** — עובד גם, אבל מגיב לפקודות backdoor שחלק מהקוראים המתקדמים
  מזהים. זול יותר, פחות אמין.

### טיפ הדבקה על הטלפון

הגב של הטלפון (מתכת + סלילי NFC/טעינה אלחוטית) משבש את המדבקה. פתרונות:

1. מדבקה עם שכבת `anti-metal` / `ferrite` — מיועדת להדבקה על מתכת.
2. או להניח את המדבקה **בתוך כיסוי הטלפון** (בין הכיסוי לגב) ולא ישירות על המתכת.

## תהליך הכתיבה ב-MCT — צעד אחר צעד

### שלב 1 — קריאת הכרטיס המקורי

1. פתח **MIFARE Classic Tool (MCT)**.
2. ודא ש-NFC דלוק.
3. `READ TAG` → הצמד את הכרטיס המקורי.
4. MCT ינסה מפתחות ברירת מחדל (`std.keys`). אם הכל ירוק — מצוין.
5. שמור את התוצאה: `Save Dump` → תן שם (למשל `my-card`).

### שלב 2 — כתיבת המדבקה

1. חבר/הצמד את **מדבקת ה-Magic** לגב הטלפון.
2. במסך הראשי → `WRITE TAG` → `WRITE DUMP (CLONE)`.
3. בחר את ה-Dump ששמרת (`my-card`).
4. **חשוב:** ודא שהאפשרות לכתוב את **בלוק 0 (Manufacturer block)** מסומנת —
   זה מה שמעתיק את ה-UID. (ב-MCT: "Enable writing to manufacturer block" /
   סימון בלוק 0 ברשימה.)
5. `OK` → המתן לסיום הכתיבה.

### שלב 3 — אימות

1. `READ TAG` על המדבקה החדשה.
2. ודא ש-`UID` זהה למקור וש-`BCC` תקין.
3. בדוק בקורא האמיתי — הצמד את המדבקה/הטלפון ובדוק שהדלת נפתחת.
